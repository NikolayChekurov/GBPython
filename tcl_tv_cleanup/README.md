# Очистка телевизора TCL от лишних приложений

Скрипт `tcl_cleanup.py` отключает рекламу, телеметрию и ненужные предустановленные
приложения на телевизорах TCL с Android TV / Google TV через ADB. Root не нужен,
все изменения обратимы.

## 1. Подготовка телевизора

1. **Настройки → Система → О системе** (или «Об устройстве») → 7 раз нажмите
   на **«Сборка ОС Android TV»**, пока не появится «Вы стали разработчиком».
2. **Настройки → Система → Для разработчиков** → включите **«Отладка по USB»**
   (на некоторых моделях также **«Отладка по сети»** / ADB over network).
   Если пункта «по сети» нет — это нормально: на Android TV «Отладка по USB»
   обычно сама открывает ADB по сети на порту 5555, просто подключайтесь по IP.
3. Узнайте IP телевизора: **Настройки → Сеть и Интернет → ваша сеть**.

Если `connect` пишет `failed to connect` / `Connection refused`:

- выключите и снова включите «Отладку по USB», затем полностью перезагрузите ТВ
  (выдерните из розетки на минуту) и повторите `connect`;
- проверьте, что компьютер в той же сети (не гостевой Wi-Fi роутера) и IP
  указан верно;
- на Google TV (Android 11+) поищите в «Для разработчиков» пункт
  **«Беспроводная отладка»**: там будет IP:порт и код сопряжения —
  выполните `adb pair IP:порт`, затем `python tcl_cleanup.py connect IP:порт`
  с портом из этого экрана;
- без компьютера: на Android-телефоне в той же сети можно поставить приложение
  с встроенным ADB (например, *Bugjaeger* или *Remote ADB Shell*), подключиться
  к `IP_ТВ:5555` и выполнять команды `pm disable-user --user 0 <пакет>` вручную.

USB-кабель «компьютер ↔ ТВ» обычно не работает: USB-порты телевизора
предназначены для флешек, а не для подключения к ПК.

## 2. Подготовка компьютера

- Python 3.8+
- [Android Platform Tools](https://developer.android.com/tools/releases/platform-tools)
  (`adb` должен запускаться из командной строки).
- Компьютер и ТВ — в одной сети.

## 3. Использование

```bash
python tcl_cleanup.py connect 192.168.1.50   # на ТВ нажмите «Разрешить»
python tcl_cleanup.py list                   # что найдено из списка
python tcl_cleanup.py clean                  # пробный прогон — только план
python tcl_cleanup.py clean --apply          # отключить рекламу/телеметрию
python tcl_cleanup.py speedup --apply        # ускорить анимации, почистить кэш
adb reboot
```

Дополнительно:

- `clean --apply --level optional` — также Netflix, Prime Video, YouTube Music,
  Play Игры и т.п. Внимательно посмотрите план: например, `katniss` — это
  голосовой поиск/Ассистент.
- `clean --apply --uninstall` — удалить для пользователя (освобождает место),
  а не просто отключить.
- `clean --apply --extra com.example.app` — добавить пакет вручную.
- `list --all` — все пакеты TCL и сторонние, чтобы выбрать что-то ещё.

## 4. Если что-то пошло не так

```bash
python tcl_cleanup.py restore                  # вернуть всё из журнала
python tcl_cleanup.py restore com.tcl.weather  # вернуть один пакет
```

Журнал изменений хранится в `removed_packages.json` рядом со скриптом.
В крайнем случае поможет сброс к заводским настройкам — системные приложения
из прошивки при этом возвращаются.

## Безопасность

- Ключевые системные пакеты (лаунчер, настройки, тюнер, Google Play Services,
  клавиатура и т.д.) находятся в защищённом списке и не трогаются никогда.
- По умолчанию всё запускается как пробный прогон, а перед изменениями
  запрашивается подтверждение.
- Имена пакетов различаются между моделями — скрипт работает только с теми,
  что реально установлены на вашем ТВ.

## Что ещё ускоряет TCL

- Отключите **«Мгновенное включение / Quick Start»**, если ТВ тормозит после
  пробуждения, — полная перезагрузка освобождает память.
- В Google TV включите **«Режим «Только приложения»** — главный экран
  перестанет подгружать рекомендации.
- Регулярно перезагружайте ТВ (отключение от сети на 1 минуту).
